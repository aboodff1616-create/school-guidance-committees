خدمة الذكاء الاصطناعي

ضع رابط API لخادمك الآمن الذي يتولى الاتصال بمزوّد الذكاء الاصطناعي. يجب أن يستقبل POST بصيغة JSON: {task, context} ويعيد {text}.
